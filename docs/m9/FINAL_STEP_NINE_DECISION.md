# 第九步最终机构决策

## 结论

第九步已按冻结规则终态收口为：

```text
HOLD_REAUTHORIZATION_CONTRACT_INVALID
```

这不是 PeerLite 的正面或负面 Alpha 结论。它表示旧 M8 的确认运行发生了
不可重试的权威账本事故，而且其子契约错误地声明未看过决定性结果。修复
尝试已诚实改为 `decisive_outcomes_seen=true`，官方 `quant_contract_v2`
验证器因此拒绝这份子契约。该草案还同时存在试验预算字段不一致，以及
子契约 `decisive_outcomes_seen=true` 与变更请求
`outcome_reviewed=false`、`final_oos_replaced=false` 不一致的问题。

这份证据只能证明当前再授权尝试无效，不能证明未来不存在可行的新 OOS。
复用 2025-01-01 至 2026-06-30、把结果查看声明改回 false，或先训练后补
契约都会降低冻结标准，因此当前研究周期停止。

## 已完成的机构动作

- 原 M8 失败证据、运行字节、权威账本和审查结论保持不变。
- 新契约修复尝试在任何训练之前被官方验证器拒绝并完整保留。
- 没有新增候选评估或模型 fit；账本仍为 9 次候选评估、64 次 fit 启动。
- 最终 OOS 访问日志仍为原始字节，访问次数和选择使用次数均为 0。
- PeerLite K16 MSE 只保留为预最终 OOS 研究基线，不晋级、不接生产。

## 决策含义

原九步研究计划已经产生一个合法终态 `HOLD`。如果未来继续，不属于对旧
M8 的重跑，而是新的研究周期：先建立内部一致的变更请求和子契约，前瞻
冻结一个与所有历史 OOS 不重叠的区间，等待区间充分累积，再执行新的确认
和一次性最终评价。当前证据不对这种未来路径的可行性作肯定或否定判断。
